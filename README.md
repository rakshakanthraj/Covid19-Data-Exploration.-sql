# Project Overview

This project explores global COVID-19 data using SQL. The analysis is performed on a dataset containing information about COVID-19 cases, deaths, population, and vaccinations. The project demonstrates key SQL skills, including:

Joins

Common Table Expressions (CTEs)

Temporary Tables

Window Functions

Aggregate Functions

Creating Views

Data Type Conversions

Dataset Information

# The project uses two primary datasets:

CovidDeaths: Contains data on total cases, new cases, total deaths, and population by country and date.

CovidVaccinations: Contains data on COVID-19 vaccinations, including new vaccinations per day.


# SQL Techniques Used

Common Table Expressions (CTEs): Used for breaking down complex queries into smaller logical parts.

Temporary Tables: Used for intermediate storage of calculated values.

Joins: Used to merge COVID-19 case data with vaccination data.

Views: Created to store and reuse data for later visualizations.
